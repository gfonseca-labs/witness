# Witness v0.1.0 limitations and follow-ups

See [release scope](RELEASE-APPROVAL-v0.1.md) for the published technical scope,
[validation](VALIDATION-v0.1.md) for release evidence and installation, and the
[threat model](THREAT_MODEL.md) for current security assumptions.

The v0.1.0 release does not resolve filesystem durability, parent-directory
symlink handling, resource limits or Linux/Windows validation. These topics
are tracked in [#1](https://github.com/gfonseca-labs/witness/issues/1),
[#2](https://github.com/gfonseca-labs/witness/issues/2) and
[#3](https://github.com/gfonseca-labs/witness/issues/3).

No independent security audit, separate-user usability trial or demonstrated
demand is established by the published release evidence. Article and social
publication were deferred. Release preparation checklists are not current
user instructions or evidence that publication is still pending.
